Project Overview

Snow Surfer is a 2D physics-based snow skating game built in Unity using C#. You control a skater racing down a curved, snowy hill — accelerate, hit natural jumps, pull off stunt rolls mid-air, and land cleanly to keep going. Go upside down and the run is over.

Built solo as part of my Udemy Unity learning journey, this project was a deep exploration of Unity's 2D terrain and physics tools — Sprite Shape for organic hill design, Edge Colliders for accurate surface collision, Surface Effector for the smooth sliding feel, and Cinemachine to keep the camera glued to the action.

Key Features

  • Smooth physics-driven skating down a curved snowy hill
  • Stunt Rolls — perform mid-air rolls for style, but land right-side up!
  • Crash Detection — going upside down ends the run immediately
  • Cinemachine Camera — dynamically follows the skater down the full hill
  • Finish Flag — reach the end of the hill to complete the run
  • Organic curved terrain built with Sprite Shape for a natural hill feel

Core Systems

  • Sprite Shape — Unity's Sprite Shape tool used to design smooth, curved 2D hill terrain
  • Edge Collider 2D — collision boundary precisely follows the hill surface shape
  • Surface Effector 2D — applies constant directional surface force for natural downhill momentum
  • Cinemachine — dynamic follow camera that tracks the skater smoothly across the full level
  • Namespaces — C# scripts organised into clean namespaces to avoid conflicts and improve structure
  • Invoke — Invoke() used for timed method calls such as crash sequences and stunt resets

What I Learned

  • Designing smooth 2D curved terrain using Unity's Sprite Shape tool
  • Setting up Edge Collider 2D to match complex organic surface shapes
  • Using Surface Effector 2D to create a natural sliding feel without manual force scripting
  • Configuring Cinemachine for smooth dynamic camera follow in a side-scrolling level
  • Structuring C# code cleanly using Namespaces across multiple scripts
  • Triggering timed game events cleanly with Invoke() instead of coroutines
