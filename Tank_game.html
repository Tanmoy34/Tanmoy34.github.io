Project Overview

Tank Game is a third-person tank combat game built entirely in Unreal Engine 5 using C++. The player controls a tank, aims at targets, and fires — with responsive controls powered by UE5's Enhanced Input System and satisfying hit feedback through camera shake and Niagara particle effects.

Developed solo in just 6 days as part of my Udemy Unreal Engine C++ learning journey, this project demonstrates core gameplay programming skills including C++ input handling, camera feedback systems, and visual effects integration.

Key Features

  • Tank movement and turret aiming with smooth, responsive controls
  • Enhanced Input System — fully implemented in C++ using UE5's new input framework
  • Camera Shake — triggers on successful target hit, providing tactile feedback
  • Niagara Particle Effects — visual effects for projectile impact and explosions
  • Control Widget scripted in C++ for clean UI integration

Core Systems

  • Enhanced Input System (C++) — Input Mapping Context and Input Actions configured and bound entirely in C++
  • Camera Shake System — base CameraShake class extended in C++ and triggered on projectile hit events
  • Niagara Particles — general-purpose particle systems for hit and explosion visual feedback
  • Control Widget — C++ scripted widget displaying player controls in-game
