Project Overview

DeliveryDash is a 2D top-down delivery game built in Unity 6 using C#. You drive an ice-cream van through a cozy neighborhood map, picking up packages and delivering them to the correct doorstep — all while navigating obstacles and collecting speed boost orbs along the way.

Built solo as part of my Udemy Unity 2D learning journey, this project focuses on cementing core Unity fundamentals: transforms, input handling, prefabs, collision, and frame-rate-independent movement using Time.deltaTime.

Key Features

  • Smooth top-down van movement and rotation using Unity's New Input System
  • Package Pickup & Delivery — drive over packages to collect, reach the floor marker to deliver
  • Boost Orbs — collectible orbs that temporarily increase van speed
  • Obstacles — interactive hazards placed throughout the neighborhood map
  • Cozy top-down village map with streets and navigable paths

Core Systems

  • Unity New Input System — modern input reading for van movement and rotation
  • Transforms & Rotation — smooth directional movement scripted in C#
  • Prefabs — reusable objects for packages, obstacles, and boost orbs for efficient level design
  • Collision Detection — trigger-based pickup and delivery logic
  • Time.deltaTime — frame-rate-independent movement and animations

What I Learned

  • Moving and rotating game objects smoothly based on player input
  • Unity's modern Input System for clean input handling in C#
  • Building and using Prefabs for efficient, reusable level design
  • Writing gameplay logic, movement scripts, and collision handling in C#
  • Making movement frame-rate independent with Time.deltaTime
