Project Overview

TilesMania is a 2D tile-based platformer built in Unity using C#, inspired by classic games like Mario. Navigate through grid-built levels, avoid traps, shoot enemies in your way, and find the exit gate to advance to the next stage.

Built solo as part of my Udemy Unity learning journey, this project was a comprehensive dive into Unity's Tilemap system, game architecture patterns like Singleton and Game Session, enemy and bullet scripting, and building functional game UI from scratch.

Key Features

  • Tile-built levels using Unity's Tilemap and Rule Tile system
  • Enemy AI — patrol movement, player detection, and death logic
  • Bullet System — shoot projectiles to defeat enemies
  • Level Loading — smooth scene transitions on level complete or player death
  • Singleton Game Manager — persistent manager surviving scene changes
  • Game Session — carries player lives and score across all levels
  • Full Unity UI — HUD (score, lives) and game over / menu screens

Core Systems

  • Sorting Layers — controls render order for backgrounds, tiles, characters, and UI
  • Tilemap & Rule Tile — grid-based level design with automatic context-aware tile placement
  • Enemy Script — patrol, detect, and death behaviour written in C#
  • Bullet Logic — projectile spawning, direction, travel, and collision destruction
  • Level Loading — scene management for next level and restart on death
  • Singleton — single persistent GameManager instance across all scenes
  • Game Session — persistent object tracking lives and score between levels
  • Unity UI — HUD, main menu, and game over screens

What I Learned

  • Designing tile-based levels efficiently using Tilemap and Rule Tiles
  • Managing render depth correctly with Sorting Layers
  • Writing enemy patrol AI and bullet projectile logic in C#
  • Implementing the Singleton pattern for persistent game managers
  • Using a Game Session object to carry state across multiple scene loads
  • Building complete UI flows — HUD, menus, and game over screens with Unity UI
