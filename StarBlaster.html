Project Overview

Star Blaster is a 2D space shooter built in Unity using C#. You pilot a spaceship at the bottom of the screen, shooting down enemy planes that follow predefined flight paths. Survive the waves and rack up the highest score you can before your ship is destroyed.

Built solo as part of my Udemy Unity learning journey, this project was a focused exercise in C# programming fundamentals — arrays, loops (for, foreach, while), and coroutines — combined with satisfying game feel systems like screen shake, particle collision explosions, and a live scoring system.

Key Features

  • Enemy Pathfinder — enemies navigate a sequence of waypoints across the screen
  • Particle Collision — explosion particle effects triggered on bullet-to-enemy impact
  • Screen Shake — camera shake on player hit for satisfying impact feedback
  • Scoring System — live score counter that updates as enemies are destroyed
  • Coroutine-driven Spawning — timed enemy wave spawning with delays between waves
  • Endless waves with increasing enemy pressure

Core Systems

  • Arrays — stores enemy wave configs and waypoint sequences for pathfinding
  • For Loop — iterates through waypoints and enemy spawn lists
  • Enemy Pathfinder — waypoint-based movement system where enemies travel between defined positions in sequence
  • Coroutines — IEnumerator / StartCoroutine for wave spawn timing and movement delays
  • Foreach Loop — cleanly iterates over active enemy and object collections
  • While Loop — continuous game state and wave loop logic
  • Particle Collision — explosion effects triggered by bullet-to-enemy collision events
  • Screen Shake — camera shake system triggered on player damage
  • Scoring System — real-time score tracking and HUD display

What I Learned

  • Using Arrays to store and access structured game data like waypoints and wave configs
  • Applying For, Foreach, and While loops in real gameplay logic
  • Building a waypoint-based enemy pathfinder from scratch in C#
  • Sequencing timed enemy spawning with Coroutines
  • Triggering particle explosion effects on physics collision events
  • Implementing screen shake for game feel and player feedback
  • Building and displaying a real-time scoring system on the HUD
