Project Overview

Store Simulator is a 3D store management game built in Unity using C#. You play as the store owner — set up your shop, then watch customers arrive one after another, browse the shelves, and make their way to the checkout counter. Complete each transaction to send them off and keep the line moving.

Built solo as part of my Udemy Unity learning journey, this project was a deep dive into intermediate and advanced C# concepts: the event system, coroutines, lists, prefabs, instances, and multi-script architecture all working together in a real simulation loop.

Gameplay Loop

  • Customer enters the store and begins browsing
  • Customer picks items from the shelves
  • Customer walks to the checkout counter
  • Player completes the transaction
  • Customer leaves — next customer arrives

Core Systems

  • Event System — C# events and delegates decouple customer state changes (e.g. shopping complete → trigger checkout)
  • Coroutines — IEnumerator / StartCoroutine sequences customer arrival, shopping timers, and checkout flow
  • Lists — List<T> dynamically manages customer queues and item inventories
  • Prefabs & Instances — reusable customer and item prefabs instantiated at runtime
  • Multiple Scripts — responsibilities split across CustomerController, ShopManager, CheckoutCounter, and more for clean, maintainable code

What I Learned

  • C# basics and advanced features applied in a real game simulation context
  • Designing decoupled systems using C# events and delegates
  • Managing dynamic object queues and inventories with List<T>
  • Sequencing timed behaviour cleanly using Coroutines
  • Structuring a project across multiple scripts with clean references and instances
  • Building and instantiating Prefabs at runtime for scalable level design
